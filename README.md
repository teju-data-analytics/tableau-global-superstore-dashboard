# Global Superstore Sales Dashboard

Author: Maria Tejaswini Polishetty

## Project Overview
This project analyzes the performance of a global retail company using the Global Superstore dataset. Tableau dashboards were created to visualize sales trends, profitability, geographic performance, and product returns between 2013 and 2015.

## Key Insights
Technology generated the highest sales and profits.

Furniture had strong sales but lower profit margins.

The United States and Europe were the most profitable regions.

Sales orders increased steadily from 2013 to 2015 while returns remained relatively low.
